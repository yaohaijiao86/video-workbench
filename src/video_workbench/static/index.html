视频与媒体探测 · FFmpeg / ffprobe FFmpeg 必需

官方下载入口 → Windows 构建包；配置 exe 完整路径。若没有 ffprobe，程序会用 FFmpeg 读取常见视频的时长和音轨；完整 ffprobe 对复杂封装更可靠。运行 ffmpeg -version 验证。

编码慢通常因为 CPU x264 需要逐帧重算。可在“精剪视频输出”选择 x264 快速，或在 FFmpeg 包含 NVENC 且 NVIDIA 驱动正常时选择 NVIDIA GPU。首次建议用短片比较速度和画质。

语音识别与对齐 · Qwen3-ASR 中文优先

官方安装文档。独立环境运行 pip install -U qwen-asr。设置页已预置通用命令和适配脚本；如需独立环境，把命令数组首项改为该环境的 Python 完整路径。模型默认使用 Qwen/Qwen3-ASR-1.7B 和 Qwen/Qwen3-ForcedAligner-0.6B，首次运行时按官方包行为下载；也可在上方填写本地模型目录。README 提供完整命令示例。

若 GPU 服务器在另一台电脑，可在显卡机运行 examples/asr_qwen3_server.py，本机 ASR 命令改用 examples/asr_remote_client.py；需要两端相同的密钥文件，并按实际网络设置服务地址。步骤见 README 中的双机部署说明。

中文、方言和切点准确性优先时推荐 1.7B 加对齐器；0.6B 更省资源。官方包分块处理长音频，适配器输出字词级时间戳。

ASR 备选 · faster-whisper / FunASR 可替换

faster-whisper：独立环境安装后配置仓库的 examples/asr_faster_whisper.py，多语种选 large-v3，速度优先可选 turbo。FunASR 可选 SenseVoice/Paraformer，需适配脚本输出时间戳 JSON。

取 10–20 分钟真实素材比较字错率与切点误差；没有一个模型对所有口音与噪声都最好。

语义判断与总结 · 本地或在线模型 必需

没有本地大模型时，可添加在线模型配置，填写服务商提供的 HTTPS API 地址、API Key，扫描后在“模型配置优先级”里点击剪辑建议、章节总结或画面识别，再逐个点击可调用模型加入任务列表。每条配置可单独选择本地/局域网或在线 OpenAI 兼容服务；字幕文本和启用画面识别时抽取的截图会发送到所选服务商。

本地/局域网任务前，先确认模型所在机器和推理服务在线，并确认所选模型已加载或服务支持按需加载。自建网关模式会在任务结束后通过 9990 停止推理引擎，8787 API 和 9990 管理界面继续运行；该停止接口可能影响同机其他程序。NInfer、Strata、LM Studio、llama.cpp 等其他服务请选择手动管理，任务结束后在服务端卸载模型或停止引擎以释放内存/显存。

优先选择中文理解与 JSON 输出稳定的模型。数字、否定、专有名词、重复句要人工核对；删除建议会默认显示删除线，请在字幕框中复核。

视觉理解 · Qwen3-VL 配图可选

官方仓库。独立推理服务加载适合 24GB 显存的视觉版本，暴露兼容图片输入的 Chat Completions 接口，填写视觉模型 ID 并先测试图片请求。

较大模型通常更稳但更慢、更占显存。本程序逐章抽帧分析；单帧不能代表整段视频。

画面文字 · PaddleOCR 可选

官方仓库；在独立环境按官方文档安装 PaddlePaddle 与 paddleocr。OCR 命令调用 examples/ocr_paddle.py --image {image} --output {output}；完整 JSON 数组示例见 README。

幻灯片、屏幕录制适合开启；纯口播收益低。专用 OCR 往往比视觉模型更可靠地识别小字。

镜头检测 · PySceneDetect / TransNetV2 可选

PySceneDetect 官方仓库：独立环境运行 pip install scenedetect。场景命令调用 examples/scene_pyscenedetect.py --video {video} --output {output}；完整 JSON 数组示例见 README。TransNetV2 是神经网络备选，可自行接入相同的 {"times":[12.5,25.0]} 输出协议。

运动镜头可先试 AdaptiveDetector；转场复杂的素材可对照 TransNetV2。两者均需用真实素材核查漏检和误检；固定机位口播可以跳过。检测点只用于挑选截图，不决定剪辑删除。
