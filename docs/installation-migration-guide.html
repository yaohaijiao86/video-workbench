“语音识别中”是谁在工作？

当前由单独安装的 Qwen3-ASR 1.7B 负责听音频，Qwen3-ForcedAligner 0.6B 负责生成精剪需要的字词级时间戳。

本机模型 API

文本／视觉服务

在设置页填写 OpenAI 兼容服务地址、模型 ID，并按服务要求设置 API Key。请先验证模型列表和一次简单请求。

可选远程 ASR

远程语音识别

将 ASR 客户端配置为 GPU 主机提供的服务地址。服务端和客户端应使用同一个令牌文件，并允许工作台主机访问 ASR 端口。

“外部模型未提供百分比”并不是错误。 当前 ASR 适配器只在处理完成时写入结果，没有向工作台报告已处理的音频时长；因此界面是活动条而非数字百分比。完成后显示 100%。已有 SRT 的项目会跳过语音识别。

代码位置：src/video_workbench/workbench.py → task_transcribe() 提取音频并设状态；src/video_workbench/services.py → run_asr() 执行配置命令；examples/asr_qwen3.py 调用外部模型。文本／视觉大模型用于分析和总结，不承担当前 ASR。

仓库只有工作台代码和适配脚本，不附带软件、Python 环境或模型权重。按要启用的功能安装即可。

方案 A · 新电脑单机安装

以下以解压工作台到 D:\video-workbench、独立环境到 D:\VWEnv 为例。路径可以更换，设置页必须与实际路径一致。

1

下载 Python、源码和 FFmpeg

从上表官方入口安装 Python 3.12 64 位。将工作台源码 ZIP 解压到 D:\video-workbench；FFmpeg Windows 构建解压到 D:\Tools\ffmpeg。

PowerShell 
py -3.12 --version
& D:\Tools\ffmpeg\bin\ffmpeg.exe -version
& D:\Tools\ffmpeg\bin\ffprobe.exe -version
& D:\Tools\ffmpeg\bin\ffmpeg.exe -encoders | Select-String libx264
2

创建独立 ASR 环境

先在 PyTorch 官方安装选择器 选择 Windows／Pip／CPU，把生成的安装命令改用下面环境的 python.exe -m pip 执行。有 NVIDIA GPU 时改选兼容的 CUDA 版本。不要直接复制旧电脑的虚拟环境。

PowerShell 
py -3.12 -m venv D:\VWEnv\asr
& D:\VWEnv\asr\Scripts\python.exe -m pip install --upgrade pip
# 此处先执行 PyTorch 官方选择器生成的 CPU 或 CUDA 安装命令
& D:\VWEnv\asr\Scripts\python.exe -m pip install qwen-asr==0.0.6 hf_xet modelscope
& D:\VWEnv\asr\Scripts\python.exe -c "import torch,qwen_asr; print(torch.__version__,torch.cuda.is_available())"

固定 qwen-asr==0.0.6 与本项目当前适配器验证环境一致；升级后先用短样片复测。

3

下载两个模型权重

Qwen 官方在中国大陆推荐 ModelScope。若旧机器已有完整模型目录，可直接复制并核对文件；其余情况下载到独立目录。

PowerShell 
& D:\VWEnv\asr\Scripts\modelscope.exe download --model Qwen/Qwen3-ASR-1.7B --local_dir D:\VWModels\Qwen3-ASR-1.7B
& D:\VWEnv\asr\Scripts\modelscope.exe download --model Qwen/Qwen3-ForcedAligner-0.6B --local_dir D:\VWModels\Qwen3-ForcedAligner-0.6B

也可按 官方 README 用 Hugging Face 下载；模型与下载缓存请留足空间。

4

启动工作台，填写设置

程序本身只用 Python 标准库。打开 http://127.0.0.1:8765，进入右上角“设置”；填写 FFmpeg 和 ffprobe。添加模型配置后，分别填写服务类型、模型 API 地址和（如需要）API Key。扫描结果会显示在“模型配置优先级”中；先点任务名称按钮，再逐个点模型加入，并可上下移动调整尝试顺序。ASR 模型通过独立命令配置。

PowerShell 
cd D:\video-workbench
py -3.12 run.py
设置 → ASR 命令参数数组 · CPU 示例 
["D:\\VWEnv\\asr\\Scripts\\python.exe","D:\\video-workbench\\examples\\asr_qwen3.py","--input","{audio}","--output","{output}","--model","D:\\VWModels\\Qwen3-ASR-1.7B","--aligner","D:\\VWModels\\Qwen3-ForcedAligner-0.6B","--device","cpu","--cache-dir","D:\\VWModels\\hf-cache"]

ASR 设置是 JSON 参数数组；Windows 路径在 JSON 中写双反斜杠。有 GPU 且 CUDA 检查为 True 时才把 cpu 改成 cuda:0。

方案 B · GPU 远程语音识别

工作台和文本／视觉模型服务运行在本机；在 ASR_SERVER_IP 安装独立 ASR 服务。ASR 与模型 API 是两条独立连接。

工作台本机

FFmpeg＋远程客户端

提取 WAV，调用 examples\asr_remote_client.py，把音频经局域网发往 ASR_SERVER_IP:8877。此模式下工作台本机不必安装 qwen-asr。

显卡机 ASR 主机

CUDA ASR＋两个模型

运行 examples\asr_qwen3_server.py。它调用 Qwen3-ASR 和 ForcedAligner，输出带时间戳结果。

1

在显卡机安装 NVIDIA 驱动、CUDA PyTorch、Qwen

从 NVIDIA 官方站点 安装驱动；安装 Python 3.12。把 asr_qwen3.py 和 asr_qwen3_server.py 放到显卡机同一 examples 目录。创建环境后先按 PyTorch 官方选择器安装适合驱动的 Windows CUDA 版，再安装 Qwen 包，并照方案 A 第 3 步在显卡机下载模型。

GPU · PowerShell 
nvidia-smi
py -3.12 -m venv D:\VWEnv\asr
& D:\VWEnv\asr\Scripts\python.exe -m pip install --upgrade pip
# 此处先执行 PyTorch 官方选择器生成的 Windows CUDA 安装命令
& D:\VWEnv\asr\Scripts\python.exe -m pip install qwen-asr==0.0.6 hf_xet modelscope
& D:\VWEnv\asr\Scripts\python.exe -c "import torch; print(torch.cuda.is_available(),torch.cuda.get_device_name(0))"

最后一条应输出 True 和 GPU 名称；若不是，先修复驱动／PyTorch 构建。

2

生成密钥，在 ASR 主机 启动 8877

把同一密钥文件安全复制到工作台的 D:\asr-token.txt。密钥应放在仓库外，不能提交 Git。Windows 防火墙仅允许工作台 IP 访问 TCP 8877。

GPU · PowerShell 
& D:\VWEnv\asr\Scripts\python.exe -c "import pathlib,secrets; pathlib.Path(r'D:\asr-token.txt').write_text(secrets.token_urlsafe(48),encoding='utf-8')"
& D:\VWEnv\asr\Scripts\python.exe D:\video-workbench\examples\asr_qwen3_server.py --host ASR_SERVER_IP --port 8877 --token-file D:\asr-token.txt --model D:\VWModels\Qwen3-ASR-1.7B --aligner D:\VWModels\Qwen3-ForcedAligner-0.6B --device cuda:0 --cache-dir D:\VWModels\hf-cache --temp-dir D:\VWTemp

关掉这个 PowerShell 窗口会停止服务；短片验证成功后，再按需设置 Windows 任务计划程序自动启动。

3

工作台切换 ASR 命令

只替换 ASR 参数数组，不改文本／视觉模型 API。若 py 不可用，替换为工作台 Python 的完整路径。

设置 → ASR 命令参数数组 · 远程示例 
["py","D:\\video-workbench\\examples\\asr_remote_client.py","--input","{audio}","--output","{output}","--url","http://ASR_SERVER_IP:8877/transcribe","--token-file","D:\\asr-token.txt"]
显存与网络：ASR 服务逐个处理请求，并在每次转写后释放显存。8877 只用于可信局域网或 VPN，不能映射公网；音频 HTTP 传输没有额外加密。

可选模块单独安装

它们不负责“语音识别中”这一步。需要画面文字或镜头节奏分析时再安装，分别使用独立 Python 环境。

OCR · 可选

PaddleOCR / PP-OCRv5

在工作台创建 D:\VWEnv\ocr。先按 官方安装指南 安装匹配 Windows CPU 的 PaddlePaddle 推理运行时，再安装 PaddleOCR。当前脚本 examples\ocr_paddle.py；首次运行可能下载 OCR 模型。

PowerShell 
py -3.12 -m venv D:\VWEnv\ocr
& D:\VWEnv\ocr\Scripts\python.exe -m pip install paddlepaddle
& D:\VWEnv\ocr\Scripts\python.exe -m pip install paddleocr
& D:\VWEnv\ocr\Scripts\python.exe -c "import paddle,paddleocr; print(paddle.__version__,paddleocr.__version__)"

OCR 配置：["D:\\VWEnv\\ocr\\Scripts\\python.exe","D:\\video-workbench\\examples\\ocr_paddle.py","--image","{image}","--output","{output}","--cache-dir","D:\\VWModels\\paddle"]

场景 · 可选

PySceneDetect

工作台端安装即可。官方 下载页 提供 Pip 安装；适配脚本为 examples\scene_pyscenedetect.py，使用 adaptive 检测器。固定机位口播可先不启用。

PowerShell 
py -3.12 -m venv D:\VWEnv\scene
& D:\VWEnv\scene\Scripts\python.exe -m pip install --upgrade pip scenedetect
& D:\VWEnv\scene\Scripts\python.exe -c "import scenedetect; print(scenedetect.__version__)"

场景配置：["D:\\VWEnv\\scene\\Scripts\\python.exe","D:\\video-workbench\\examples\\scene_pyscenedetect.py","--video","{video}","--output","{output}","--detector","adaptive"]

需要多语种对照时可另外安装 faster-whisper large-v3 并使用 examples/asr_faster_whisper.py；Windows CUDA 依其官方说明配置 cuBLAS／cuDNN。中文精剪主方案建议先保留 Qwen3-ASR＋ForcedAligner，并用自己的样片比较错字、漏识别和时间戳偏差。

换电脑时，带走什么？

备份数据，再在新机器重建环境。源码、项目、模型权重可以复制；旧电脑的虚拟环境和绝对路径不能直接照搬。

必须

程序源码

复制本仓库源码或发行 ZIP。先在旧电脑停止程序；要保留历史，再复制工作台数据目录中的 projects、批次索引与 settings.json。

可复用

模型权重

完整复制 Qwen3-ASR、ForcedAligner、OCR 模型目录可省重新下载；新电脑仍须安装 Python、PyTorch、qwen-asr 等运行时。

必须复核

全部路径与 IP

重新设置 FFmpeg、ffprobe、ASR／OCR／场景命令、模型目录、保存目录；新工作台 IP 变化时，还要改网关可达性和 ASR 主机的防火墙来源规则。

原片路径：本机文件夹导入的项目引用旧电脑的视频绝对路径，迁移后最好保持相同路径，否则需重新导入；浏览器上传的项目目录包含原片副本。settings.json 里的路径不会自动改写。API Key 不写入该文件，重启后重新输入。
本机文本／视觉模型服务也要单独备份。 如果使用本机模型服务，迁移时另备份服务配置及权重；在新机启动服务后，先验证 /v1/models、文本请求和图像请求，再修改工作台设置。
1

确定新电脑承担什么角色

仅运行工作台：安装 Python＋FFmpeg，ASR 指向既有 ASR 主机；同时运行 CPU ASR：照方案 A；接替显卡机：照方案 B 重装并修改 IP、令牌文件与防火墙。

2

恢复项目数据

先启动一次程序生成数据目录，再停止并恢复备份；推荐独立目录保存项目：

PowerShell 
cd D:\video-workbench
$env:PYTHONPATH="src"
py -3.12 -m video_workbench.app --data "D:\VideoWorkbenchData"
3

从短片到批量逐级验收

先用 1 分钟中文视频跑转写，再检查时间戳、分析建议、导出 MP4/SRT 和生成图文 HTML；接着用 10–20 分钟真实素材检查效果，最后再跑三小时与批量工作区。

快速验收清单

  • 工作台在 127.0.0.1:8765 可打开。
  • FFmpeg、ffprobe 路径正确，libx264 可用。
  • http://127.0.0.1:8787/v1/models 返回模型列表。
  • 项目保存目录可写；历史原片路径仍有效。
  • 短片生成非空 asr.json、MP4、SRT 和 HTML。
  • 远程模式在 ASR 主机运行 nvidia-smi 可见 GPU。
  • PyTorch CUDA 返回 True；两份模型已完整下载。
  • 工作台运行 Test-NetConnection ASR_SERVER_IP -Port 8877 可连通。
  • 服务与客户端使用同一令牌文件；401 表示令牌错误或未携带。
三小时 16 kHz 单声道 PCM WAV 约 346 MB；远程 ASR 服务单次上传上限 512 MB。ASR 运行中缺少百分比是当前适配器的进度能力限制，观察项目状态及 CPU/GPU 活动即可。
